# VyomTech ERP Frontend

This directory contains the user-facing Next.js application for the ERP platform.

## Responsibilities

- tenant and admin dashboard UI
- operational modules such as sales, finance, HR, and property workflows
- lead and CRM forms and views
- analytics and KPI dashboards
- secure API-driven interaction with the backend

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Notes

This frontend is designed to consume the core backend API and should remain aligned with the API contract and tenant-aware routing model.
