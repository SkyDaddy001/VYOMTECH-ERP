# Backend application

This directory acts as the canonical backend workspace for the ERP core and service modules.

## Included responsibilities

- API and routing setup
- domain services and business logic
- authentication, authorization, and tenant enforcement
- database integration and persistence
- workflow orchestration for ERP operations

## References

The actual Go source remains under the root `cmd/`, `internal/`, and `pkg/` structure for compatibility while the platform continues to standardize and reorganize its delivery structure.
